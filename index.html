How this works — and why there is no AI in it

Every change comes from a dictionary lookup or a grammar rule you could trace by hand. No language model, no training data, no network request.

  1. Phrase bank — ~190 set expressions matched longest-first: in order to → so as to.
  2. POS tagging — suffix patterns, closed-class lists and context, so a noun is never swapped for a verb.
  3. Thesaurus — ~600 curated head words filtered by part of speech; morphology carries tense across.
  4. Structural rules — passive→active, clause fronting, sentence splitting, There is X that Y → X Y.
  5. Error injection — twelve realistic slips on a weighted pool, within a per-sentence budget.
  6. Repair pass — a/an and capitalisation corrected, so only the intended slips remain.

Quotes, citations, URLs, proper nouns and fixed terms such as machine learning are never altered.

On intended use. Introducing errors deliberately is useful for test data, grammar-checker corpora and detector research. If you are submitting the text as your own academic work, check the rules that apply to you first — paraphrasing a source without citing it is still plagiarism, whatever tool produced it.

Runs entirely in your browser. Nothing is uploaded, stored or transmitted.
